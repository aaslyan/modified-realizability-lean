The proof, and the program it realizes

Goodstein's theorem as an actual λ-term — and the realizer extract reads off it. You wanted to see it; here is the whole thing.

Two things are in play, worth not conflating. In Lean's own type theory the left column really is a λ-term — that is Curry–Howard, and why it prints as a tree. But the proof→program map for the fragment is modified realizability: extract is an explicit function sending each derivation to a realizer in a separate type — the continuous functionals PureType — keeping only witness-bearing content and giving atomic equations contentless realizers. Correctness is not the typing; it is a soundness theorem proved by induction. So the right column is not the term reread — it is the term's realizer, and the erased · nodes are the content realizability throws away.

read the left column

…and it is a proof: induction up to ε₀, a case split, a witness. Every node is a typed rule of the fragment; the tree type-checks to ∀m ∃t. good(m,t)=0.

read the right column

…and it is a program in PureType, not in φ: a transfinite recursor, a branch on a computed bit, a pair carrying the answer. extract walks the left tree and drops each node's realizer into place; soundness proves it right.

The Hydra term is this same tree

The Kirby–Paris theorem, ∀h ∃t. hydra(h,t)=0, is proved by the identical shape — tiEps0 over the same paired argument, down to the naming step. Only one erased node changes: Goodstein's ordDescent becomes Hydra's hordCutLt, the fact that one cut lowers the ordinal. Swap that leaf and the very same proof term computes battle lengths instead of stopping times.

Nothing here is a picture of the term — it is the term, node for node, as written in the source and checked by the kernel. The realizer's axiom footprint is [propext, Quot.sound]: the recursion is real, the classical content is nil.
